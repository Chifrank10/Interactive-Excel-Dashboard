# Dynamic Inventory Management System (Excel)

## Project Overview
This project is a Dynamic Inventory Management System built in Microsoft Excel to help businesses monitor stock levels, track inventory movement, automate operational reporting, and improve inventory decision-making. 

The system provides real-time inventory visibility through interactive dashboards, automated calculations, and inventory performance tracking.
## Business Problem
Many businesses struggle with:
Poor inventory visibility
Manual stock tracking
Stock shortages and overstocking
Delayed operational reporting
Inefficient inventory monitoring processes

This solution was developed to simplify inventory management and improve operational efficiency using Excel-based automation and reporting tools.

## Objectives

The main objectives of this project are:

Track stock movement dynamically
Monitor low stock items
